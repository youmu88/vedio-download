# 全屏双指缩放失效 — 根因与修复（自绘控制条 + 内联双指入口）

> 反馈（第 7 轮）：最新版本**普通全屏下双指缩放手势已经不响应**，应能放大到满屏（最大档）。
> 结论：**已真实复现到两层根因并修复**；全屏任意落点（含底部进度条带）双指都能切档，内联状态双指外扩也能直接进全屏铺满。

---

## 1. 根因（两层，第二层由第 6 轮修订引入）

**第一层：原生 `controls` 的控件带在浏览器内部吞掉触摸**

全屏沿用 `<video controls>` 的原生控件。实测（CDP 真实双指 + 页面内 `pointerdown` 捕获探针，iPhone 14 视口 390×664）：

| 位置 | 原生控件状态 | 到达页面的手指数 |
|---|---|---|
| 画面中心 y=332 | 正常 | 2 ✓ |
| 底部带 y=620 | 控件显示中 | **0** |
| 底部带 y=620 | 控件自动隐藏后 | **1** |
| 底部带 y=620 | `controls = false` | **2** ✓ |

→ 只要保留原生控件，双指落在底部控制带就凑不齐两指，**页面侧无法修复**（事件根本没到 document）。

**第二层：手势层又用 `CONTROL_GUARD` 主动丢弃底带指针**

`onDown` 里 `if (e.clientY > vr.bottom - CONTROL_GUARD) return` —— 即使事件到达也会被丢弃。实测：`controls=false` + 底部带 → 2 指到达，但 `object-fit` 没有变化（因为 JS 先 return 了）。

**第三层：上一轮把「内联双指外扩进全屏」删掉了**

第 6 轮规格只要求「退出全屏不能用手势」，实现时把「内联 → 全屏」也一起禁了。用户失去唯一不受控件带影响的入口，于是感知为「完全不响应」。

## 2. 修复内容

| 文件 | 改动 |
|---|---|
| `public/js/player-gestures.js` | **全屏改自绘控制条**：进入全屏 `video.controls = false`（消除吞事件源头），退出全屏恢复；控制条含播放/暂停按钮、可拖动进度条、当前/总时长，单击画面切换显隐、播放中 3.5s 自动隐藏、暂停保持显示 |
| 同上 | **手势监听从 `<video>` 改挂容器捕获阶段**（`box.addEventListener('pointerdown', onDown, true)`）：事件目标是 video 或控制条都先经手势层判定；落在控制条上的单指交给控件（进度条拖动/按钮），**双指由手势层接管**（并取消进行中的拖动） |
| 同上 | **底部保护区只约束单指 seek**：`downInGuard` 仅阻止单指横滑抢进度条；双指捏合不受任何落点限制 |
| 同上 | **恢复内联双指外扩**：非全屏时双指外扩 15% → 进入全屏并直接落在铺满档（任何状态都能放大到满屏）；收拢不做任何事（退出全屏仍只走顶部图标） |
| 同上 | 进度条按下不立即 seek（避免双指切档瞬间误跳），首次移动或抬起才定位；直播流（duration 无穷）禁用拖动 |
| `scripts/player-gestures-verify.mjs` | 用例 38 → 45 条：新增「原生 controls 关闭」「自绘控制条可见且进度条可点」「播放/暂停按钮」「拖动进度条定位 ≈60%」「单击切换控制条显隐」「**双指落在底部控制带仍能切档**」「内联双指外扩进全屏铺满」「桌面非全屏 ctrl+滚轮进全屏铺满」 |
| `scripts/repro-pinch-round4.mjs` | 新增多落点矩阵复现脚本（中心/偏下/底部控制带/顶部/竖直分布 + pointer 探针 + 截图） |

**为什么这是根因修法**：不再和「浏览器内部吞事件」对抗（那是页面无解的），而是把事件源头的原生控件关掉，用可控的自绘控件替代；保护区的语义也收窄成它真正要保护的对象（单指拖进度条）。

## 4. 边界与已知限制

- **自绘控制条只在全屏启用**；内联卡片仍用原生 `controls`（内联时 video 只占 40vh，控件带不遮挡手势主要落点，且内联双指外扩会立刻进全屏）。
- 控制条区域的双指判为「切档」，单指判为「控件交互」；因此**进度条拖动不会被双指误触发**，双指切档时进行中的拖动会被取消。
- 单击画面切换控制条、双击切换全屏；两次单击间隔 <320ms 会被判成双击（标准双击语义）。控制条显示时播放中 3.5 秒后自动隐藏，暂停时保持显示。
- 直播流（`duration` 为无穷）禁用进度条拖动与横滑 seek，双指切档保留。
- 自绘控制条由 `player-gestures.js` 注入 `<style id="pg-styles">`，两个播放器页面自动一致，无需改 HTML。
